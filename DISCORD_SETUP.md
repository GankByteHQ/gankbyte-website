# GankByte Discord launch checklist

## Minimum roles

- `Admin` — owner and moderation access.
- `Moderator` — rules, reports, and event support.
- `Developer` — project and code discussion.
- `Playtester` — testing and feedback.
- `Community` — default member role.

Keep administrator permissions limited to the owner. Give moderators only the permissions they need.

## First messages

Post the content in `DISCORD_WELCOME.md` in `#welcome`, pin the rules link, and post `CHALLENGE_001_POST.md` in `#announcements` or the event channel.

## Event channels

For Challenge #001, use the existing gaming/community channels. Do not create a large set of empty channels. Add an event-specific channel only once people are actively using the event.
