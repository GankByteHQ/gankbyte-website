WHAT IT CHECKS

Useful checks for the messy bits.

Manifest

Finds the NUI page, declared files, client/server scripts, and missing resource paths.

Browser files

Checks HTML, CSS, image, font, and script references without executing untrusted code.

Callbacks

Compares JavaScript NUI requests with Lua RegisterNUICallback names and flags duplicates.

Messages

Maps SendNUIMessage actions to browser message listeners so silent UI failures are easier to spot.
