WHY THIS EXISTS

Good games start
with a constraint.

Signal Forge is a tiny developer toy for turning vague ideas into specific problems. It is deliberately small, remixable, and open to community mutations.

  • No login — Forge locally and share the seed.
  • No backend — The same seed always makes the same blueprint.
  • Code included — Every result gives you a Lua-shaped starting point.
  • Make it real — Build the weirdest one, then open a project proposal.
