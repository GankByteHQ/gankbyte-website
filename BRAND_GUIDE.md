# GankByte brand guide

## Locked identity

- Name: GankByte
- Ticker: `$GKBX` (future use only)
- Tagline: Gaming. Memes. Code.
- Positioning: A gaming community and developer ecosystem first.

## Personality

Funny, chaotic, gamer-focused, developer-friendly, memetic, community-driven, and deliberately a little stupid. It should feel like gamers and developers building things they actually want to play.

## Palette

- Background: `#0A0B0F`
- Surface: `#121419`
- Surface 2: `#191B20`
- Text: `#F4F2EA`
- Muted text: `#98979B`
- Lime action: `#C6FF3D`
- Purple Arena/glitch: `#9A7BFF`
- Orange warning/heat: `#FF855C`

## Typography

The current web system uses Arial/Helvetica. Headlines are bold, tight, and oversized. Supporting text is readable and muted. Labels are uppercase and letter-spaced.

## Mascot

The original GankByte Glitch Goblin is stored as `gb-mascot.svg`. It can appear in social graphics, project cards, challenge artwork, and game thumbnails. It must not be modified into a copy of an existing game character or mascot.

## Voice rules

Lead with games, community, code, and what is actually live. Explain experiments honestly. Avoid crypto clichés, financial promises, fake hype, fake partnerships, and corporate language.
