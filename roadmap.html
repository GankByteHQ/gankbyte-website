04 // ROADMAP

Small steps.
Real things.

The plan is deliberately practical: make the community useful, ship a small project, learn from players, and earn the right to build more.

Built

GankByte v0.1 foundation

Domain, social accounts, website, Discord, Byte Rush, Glitch Dash, public source, XP system, Discord sign-in, automatic leaderboards, Projects page, contribution guide, rules, privacy notice, contact route, and custom 404 are built.

Now

Community Challenge #001

The next real-world step is to post the Byte Rush high-score event in Discord, invite the first players, run it, record feedback, and publish the results.

Next build

Arena platform

Build player profiles, run history, weekly and all-time views, challenge selection, event records, moderation tools, and shared support for future games.

After usage

Developer ecosystem

Run the contribution workflow, showcase community projects, add a first non-Byte-Rush project, and hold developer competitions once people are participating.

Only if useful

Potential token

$GKBX is not the starting point. Any future token would come only after genuine users, repeated events, useful products, and proper legal and tax review.

THE RULE

Make GankByte
real first.

If the community would not be interesting without a token, the project is not ready for a token.
