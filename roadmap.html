04 // ROADMAP

Small steps.
Real things.

The plan is deliberately practical: make the community useful, ship a small project, learn from players, and earn the right to build more.

STATUS BOARD

Live now.
Next, then later.

The public site only promises work that has a clear purpose. Finished systems are marked live; paused or future work is labelled honestly.

Live now

Play and track

Byte Rush, Glitch Dash, profiles, XP, public scores, developer projects, and the core community routes are available.

Building next

Refine the platform

Improve mobile play, moderation clarity, developer onboarding, visual polish, and feedback loops based on real use.

Later

Expand carefully

Formal events, more projects, deeper Arena tooling, and any token decision come only after genuine participation.

Live

GankByte v0.1 foundation

Domain, social accounts, website, Discord, Byte Rush, Glitch Dash, public source, XP, profiles, automatic leaderboards, project pages, contribution guidance, legal pages, and brand foundations are live.

Later

Formal community events

The Discord, community page, games, and feedback routes are ready. Formal events are intentionally paused while the product and website foundation settle.

Live

Arena platform

Player profiles, personal run history, all-time scores, rolling seven-day leaderboards, playable challenge formats, and admin review controls are live. Tournament tooling remains future product work.

Live

Developer ecosystem

Contribution guidance, project rules, proposal routes, GitHub issue templates, Byte Rush, and the public GankByte Lua Kit are available for developers and testers.

Live

Brand identity

Palette, typography, voice, usage rules, and an original vector mascot are documented and in use across the website.

Later

Potential token

$GKBX remains optional and deferred. It only becomes relevant after genuine users, useful products, repeated participation, and proper legal and tax review.

THE RULE

Make GankByte
real first.

If the community would not be interesting without a token, the project is not ready for a token.
