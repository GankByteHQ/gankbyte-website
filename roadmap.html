04 // ROADMAP

Small steps.
Real things.

The plan is practical: make the community useful, ship small projects, learn from players, and earn the right to build more.

STATUS BOARD

Live now.
Next, then later.

Finished systems are marked live. The remaining work is named plainly; real-world participation and token decisions stay outside the current build.

Live now

Play and track

Byte Rush, Glitch Dash, profiles, XP, public scores, the Arena hub, Resource Bench, developer projects, contribution routes, and the core website are available.

Activate next

Open the community loop

Share the live games, invite genuine players, collect useful feedback, and let real participation shape the next release.

Later

Grow with real people

External developer showcases, Community Challenge #001, recurring events, and larger ecosystem features wait for genuine participants. The token and wallet remain deliberately deferred.

Live

GankByte foundation

Domain, social accounts, website, Discord, two playable games, public source, XP, profiles, automatic leaderboards, project pages, legal pages, and brand foundations are live.

Live

Arena platform

Player profiles, personal run history, XP history, challenge progress, all-time scores, rolling seven-day leaderboards, playable challenge formats, and admin review controls are live.

Live

Developer ecosystem

Contribution guidance, public project proposals, issue templates, standard project actions, Byte Rush, GankByte Lua Kit, and Resource Bench are available. Resource Bench now covers Lua, FiveM, Python, web, Java, Minecraft, RuneLite, and SQL starters.

Live

Brand identity

Palette, typography, voice, usage rules, original mascot art, game thumbnails, and social preview artwork are documented and in use.

Live

Arena vNext

Event tracking, challenge and tournament records, an admin event editor, server-created run sessions, verified score submission, event standings, and a reusable adapter for future games are implemented and active.

Live

Public gameplay proof

Genuine Byte Rush and Glitch Dash gameplay and result captures are now used across the Games and Projects pages and in the public game documentation.

Later

Real community participation

Challenge #001, recurring events, and an external developer showcase begin when real participants and submissions exist. No activity or results will be invented.

Later

Potential token

$GKBX remains optional and deferred. It only becomes relevant after useful products, genuine users, repeated participation, and proper legal and tax review.

THE RULE

Make GankByte
real first.

If the community would not be interesting without a token, the project is not ready for a token.
