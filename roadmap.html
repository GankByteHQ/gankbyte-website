04 // ROADMAP

Small steps.
Real things.

The plan is deliberately practical: make the community useful, ship a small project, learn from players, and earn the right to build more.

Built

GankByte v0.1 foundation

Domain, social accounts, website, Discord, Byte Rush, Glitch Dash, public source, XP system, Discord sign-in, automatic leaderboards, Projects page, contribution guide, rules, privacy notice, contact route, custom 404, and brand guide are built.

Prepared

Community Challenge #001

The event rules, Discord welcome copy, announcement copy, XP route, and Arena event record are ready. The real-world run is now waiting for the Discord post and first players.

Foundation live

Arena platform

Player profile, XP snapshot, personal run history, all-time scores, and rolling seven-day Byte Rush leaderboards are now built. Challenge selection, event history, moderation, and broader game support remain next.

Next build

Developer ecosystem

The contribution guide, project rules, proposal route, and GitHub issue templates are ready. The first non-Byte-Rush community project and showcase still require real contributors.

Documented

Brand identity

Palette, typography, voice, usage rules, and an original vector mascot are now documented. Social banners, thumbnails, and launch artwork still need producing for the actual channels.

Only if useful

Potential token

$GKBX is not the starting point. Any future token would come only after genuine users, repeated events, useful products, and proper legal and tax review.

THE RULE

Make GankByte
real first.

If the community would not be interesting without a token, the project is not ready for a token.
