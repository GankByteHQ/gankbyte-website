04 // ROADMAP

Small steps.
Real things.

The plan is deliberately practical: make the community useful, ship a small project, learn from players, and earn the right to build more.

Now

Foundation

Establish the GankByte identity, publish the website, grow the social presence, keep the community welcoming, and use GitHub as the public home for real work.

Next

Build

Define and prototype GankByte Arena, release a small playable project, start off-chain XP, run community challenges, and invite people to test what is being made.

Later

Ecosystem

Expand into more games, tournaments, developer projects, creator programmes, tools, and community-built resources where legally permitted.

Only if useful

Potential token

$GKBX is not the starting point. Any future token would come only after a real community and product exist, with proper legal, tax, allocation, wallet, and transparency work first.

THE RULE

Make GankByte
real first.

If the community would not be interesting without a token, the project is not ready for a token.
