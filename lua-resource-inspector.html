WHAT IT CHECKS

Useful checks for real resources.

Structure

Finds missing manifests, undeclared scripts, duplicate files, and broken local require paths.

Events

Maps registrations and triggers, highlights duplicate handlers, and flags event names with no local registration.

Runtime safety

Flags infinite loops without Wait, client-side HTTP calls, suspicious dynamic code, and likely side mistakes.

Publishing

Checks for tokens, passwords, webhooks, private keys, and files that should never be committed or shared.
