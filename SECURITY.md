# Security reports

Do not publish credentials, Supabase service-role keys, database passwords, Discord secrets, private account data, or other sensitive information in a public issue.

For authentication, account, database, or credential concerns, email [contact@gankbyte.com](mailto:contact@gankbyte.com) with a clear description, affected URL or file, reproduction steps that do not expose secrets, and a safe way to reply.

The public website is a static client. The browser may contain a publishable Supabase key, but it must never contain a service-role key or database password.
