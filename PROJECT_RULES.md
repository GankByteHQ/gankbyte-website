# GankByte project rules

GankByte projects must be small enough to explain, testable by real people, and honest about their current state.

## Ownership and licensing

- Submit only code, art, audio, writing, scripts, and resources you own or are allowed to redistribute.
- Declare third-party dependencies and their licences.
- Do not include proprietary game files, extracted assets, copyrighted characters, logos, or private server content.
- Respect the terms and rules of any platform or game involved, including Lua and FiveM ecosystems.
- Choose a clear licence for contributed code before it is merged. If no licence is stated, the copyright holder retains rights and the work is not automatically reusable.

## Project quality

- Explain the smallest useful first version.
- Include setup and testing instructions.
- Record known limitations instead of presenting prototypes as finished products.
- Do not add token, financial, or investment claims to a project proposal.

## Community conduct

Contributors follow the [GankByte community rules](https://gankbyte.com/rules.html). Maintainers may reject or remove work that creates legal, safety, moderation, or platform-compliance problems.
