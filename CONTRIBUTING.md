# Contributing to GankByte

GankByte is a gaming community and developer ecosystem. Contributions should make a live game, tool, project, or community route more useful.

## Start here

Read the [developer workflow](DEVELOPER_WORKFLOW.md), then choose the smallest appropriate route:

- [Report a bug](https://github.com/GankByteHQ/gankbyte-website/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/GankByteHQ/gankbyte-website/issues/new?template=feature_request.yml)
- [Propose a project](https://github.com/GankByteHQ/gankbyte-website/issues/new?template=project_proposal.yml)

## Pull requests

1. Keep the change focused and explain the player or developer problem it solves.
2. Do not commit secrets, private information, copied game assets, or proprietary files.
3. Preserve existing licences and credit third-party work.
4. Include setup steps, screenshots, or a reproducible example when useful.
5. Describe what you checked locally and call out anything that still needs device or community testing.

## Scope and review

Small, testable work is preferred. GankByte may request a narrower first version, ownership/licence clarification, or a public proof before accepting a project for showcase.

For private matters, contact `contact@gankbyte.com`. For community discussion, use [Discord](https://discord.gg/CpWjZkjtjJ).
