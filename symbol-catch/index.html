HOW TO PLAY

Read the target.
Make the catch.

Match the symbol shown in the HUD. Catching the wrong symbol costs a life, while missed target symbols also cost a life.

  • Classic — The target changes every five correct catches.
  • Quick Switch — The target changes after every correct catch.
  • Magnet — Adds a small catch-range assist.
  • Overdrive — Adds 10% to points earned.
  • Shield — Absorbs one missed target.
